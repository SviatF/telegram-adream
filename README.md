# A_DREAM Telegram mini landing

Short conversion landing page used as an advertising bridge to the A_DREAM Telegram channel.

## Goal

One primary action across the whole page: open the A_DREAM Telegram channel and view the TOP-5 electric-car selection.

## Telegram destination

All CTA buttons currently point to:

https://t.me/adreamua

## Structure

- Premium A_DREAM hero
- TOP-5 offer
- Key content preview
- 5 locked car cards
- Value / trust blocks
- Repeated Telegram CTA
- Mobile sticky CTA
- dataLayer event `telegram_click` on every CTA

## Run locally

```bash
npm run dev
```

The project is a static site and can be deployed directly to Cloudflare Pages, Vercel, Netlify, GitHub Pages, or any static hosting.
